# Portafolio · Felipe Muñoz Zamora
Vue 3 con ES Modules, sin paso de compilación.
Ejecutar: abrir la carpeta con Live Server (VS Code) o `npx serve`. Los módulos ES no funcionan abriendo index.html con doble clic.
Publicar: subir la carpeta a un repositorio y activar GitHub Pages. Editar contenido: `js/data.js`.
